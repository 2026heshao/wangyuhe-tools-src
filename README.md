# WangYuHe 工具箱（源码）

本仓库包含作者开发的几款 Windows 小工具的源码，均基于 Python 构建，以 **MIT 许可证**开源。

## 包含工具

| 工具 | 说明 | 版本 | 安装包（Release） |
|------|------|------|------|
| **LaunchDeck** | 桌面快捷启动悬浮球 | v1.0 | [下载](https://github.com/2026heshao/wangyuhe-tools-src/releases/download/launchdeck-v1.0/LaunchDeck_setup_v1.0.exe) |
| **CacheClear** | 软件缓存清理工具 | v1.2 | [下载](https://github.com/2026heshao/wangyuhe-tools-src/releases/download/cacheclear-v1.2/CacheClear_setup_v1.2.exe) |
| **FloatPulse** | 知识库悬浮球 | v1.1 | [下载](https://github.com/2026heshao/wangyuhe-tools-src/releases/download/floatpulse-v1.1/FloatPulse_setup_v1.1.exe) |
| **PyPacker** | Python 打包辅助工具 | v1.0 | [下载](https://github.com/2026heshao/wangyuhe-tools-src/releases/download/pypacker-v1.0/PyPacker_setup_v1.0.exe) |

> 安装包通过 GitHub Releases 分发；源码在本仓库各子目录中。

## 目录结构

```
wangyuhe-tools-src/
├── LaunchDeck/    # 桌面快捷启动悬浮球
├── CacheClear/    # 软件缓存清理
├── FloatPulse/    # 知识库悬浮球
└── PyPacker/      # Python 打包辅助
```

每个子目录是独立项目，运行所需依赖见各子目录的 `README.md` / `requirements.txt`。
