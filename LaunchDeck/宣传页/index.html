问题与答案

桌面不缺软件，缺一个顺手的位置

常用的其实就那几个：浏览器、编辑器、终端、聊天工具。可它们要么散在桌面被文件盖住， 要么埋在三层开始菜单里。LaunchDeck 只解决这一件事 —— 让它们离你的鼠标只有一次滑动的距离。

极小占用

常态只是一枚球。球径 28–72px 可调，闲置时只做极轻的呼吸光影；不需要时按热键或从托盘一键隐藏，桌面立刻干净。

贴边吸附

随手把球拖到任意位置，松手自动吸附最近的左右屏幕边缘，并记住坐标；贴左缘面板向右滑，贴右缘向左滑，永远朝屏幕内侧展开。

横滑收纳

面板固定 72px 高、宽度自适应（不超过屏宽 60%），只横向滚动、没有纵向滚动条 —— 应用再多也不会糊成一片网格。

不猜、不联网

配置就是一个本地 config.json，图标在本地提取并缓存成 PNG。不发请求、不要账号、不收集任何使用数据。

四步上手

从双击到习惯，用不了一分钟

01

球落在屏幕边缘

启动后一枚球贴在屏幕左/右缘垂直居中位置。它常驻最上层，但从不抢焦点。

单实例锁 · 重复启动会提示
02

把软件丢给它

把 .exe、.lnk 快捷方式，甚至 PDF、文件夹、网址直接拖到球或面板上即可添加 —— 名称和图标自动读取。

拖入即添加
03

滑出去，点一下

鼠标移到球上，面板向屏幕内侧滑出；点图标即启动，带一次收缩回弹的确认反馈。移开鼠标自动收回，也可固定常驻。

650ms 点击冷却防误连点
04

按喜好调一遍

右键打开设置：图标大小、球径、面板透明度、动画速度、三套配色、全局热键、鱼眼放大、频率排序，改完即时生效。

功能图鉴 · 壹

一枚球，两种状态

尺寸可调 28 – 72px
  • 静置时几乎不存在 软投影柔和、无发光无边框，只在鼠标靠近时微微放大 —— 不干扰也不会被忽略。
  • 呼吸光影可关 闲置时 2.8 秒一轮的极缓呼吸，呼吸与悬停两套动画严格互斥，不会为了好看而掉帧；不想要就在设置里关掉。
  • 整颗球可换贴图 支持 PNG / JPG / BMP / WebP，任意比例自动居中裁成圆形。建议方形图 ≥ 256×256，选图后自动备份，原文件可删。
  • 拖不动也丢不了 拖动结束自动吸附到最近的左右屏幕边缘，ball_x / ball_y 记进配置，重启后还在原地。

功能图鉴 · 贰

面板里的四个小细节

设计上刻意克制：每项就是「图标 + 一行名字」，没有托盘区、没有分组树、没有拖不动的网格。

72px 高 · 横向滚动
  • 悬停高亮渐入 120ms 渐变插值而非硬切；启动时图标收缩回弹 + 一圈波纹扩散，明确告诉你「点到了」。
  • 鱼眼放大（可关） 鼠标在面板上移动时，附近 110px 内的图标随之放大 —— RocketDock 式的顺手感，逐帧收敛，标签自动淡出让位。
  • 运行中指示点 每 2 秒检查一次进程，已在运行的应用图标右下角亮起小圆点；点击这类应用会把它切到前台，而不是再开一个。
  • 失效条目标记 目标文件被删除或移动后，图标自动减淡并打上琥珀色 ! 角标，悬停提示还能显示原路径，不必再逐个点开试。
  • 面板内直接拖拽排序 按住图标横向拖动即可重排顺序，不用回去翻设置；若开启频率排序，则按「启动次数 → 最近使用」自动排列。

常驻入口

三条路，都能把它叫回来

悬浮球藏起来之后不会「消失不见」：热键、托盘、右键菜单三条入口行为完全一致， 你永远不会找不到它。

Alt + Space

默认 Alt + Space 显示 / 隐藏悬浮球，可在设置里录制任意组合键（需含 Ctrl / Alt / Shift / Win 修饰键）。 热键由独立工作线程监听，按住不重复触发。
提示：Alt + Space 会全局屏蔽系统的窗口控制菜单，如常用可改成 Ctrl + Alt + L。

热键 · 托盘左键 · 右键菜单「设置 / 退出」
